# Expense Tracker CLI

A simple command-line expense tracker built with pure Python (no external libraries). I built this project while learning Python to practice real-world program design.

## Features
- Add an expense (amount, category, date)
- View all expenses
- Delete an expense (numbers re-order automatically)
- Calculate total spending
- Menu-driven interface

## Concepts Practiced
- Lists and dictionaries
- Functions
- Loops and conditionals
- Type conversion
- Menu-driven program design

## How to Run
1. Install Python 3
2. Clone this repo
3. Run:
   py expense_tracker.py
